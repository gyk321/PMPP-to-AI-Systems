《Programming Massively Parallel Processors》**第三章“多维网格与数据”（Multidimensional Grids and Data）** 主要介绍了 CUDA 中线程的组织结构以及如何将多维线程映射到多维数据集。以下是本章核心内容的详细总结：

### 3.1 多维网格组织 (Multidimensional Grid Organization)

在 CUDA 中，所有属于同一个网格（Grid）的线程都会执行同一个核函数（Kernel），它们依赖内置坐标变量（线程索引）来标识各自需要处理的数据部分。

- **层次结构与维度：** CUDA 线程组织是一个**两级层次结构**：网格由一个或多个线程块（Block）组成，而每个块又由一个或多个线程组成。一般而言，网格和块都可以在三个维度（X, Y, Z）上进行配置。
- **`dim3` 类型：** 核函数的配置参数采用 `dim3` 类型定义（若省略某些维度，则其默认大小为 1）。例如，可以利用 `dim3 dimGrid(2, 2, 1)` 和 `dim3 dimBlock(4, 2, 2)` 配置网格和块的维度。
- 内置变量：
  - `gridDim` 与 `blockDim` 分别表示网格和线程块在各个维度上的大小。
  - `blockIdx` 与 `threadIdx` 分别是当前线程所在的线程块坐标和块内线程坐标，均包含 `.x`、`.y`、`.z` 三个字段。
- **硬件限制：** 目前 CUDA 系统中，**单个线程块（Block）的最大线程数限制为 1024**。

### 3.2 线程到多维数据的映射 (Mapping Threads to Multidimensional Data)

在处理图像、矩阵等本身就具有多维性质的数据时，使用多维的线程组织可以提供极大的便利。

- 2D 坐标计算公式：以处理像素数据为例，我们可以利用以下公式计算每个线程所对应数据在网格中的行（row）和列（col）坐标：

  - $$\text{row} = \text{blockIdx.y} \times \text{blockDim.y} + \text{threadIdx.y}$$

  - $$\text{col} = \text{blockIdx.x} \times \text{blockDim.x} + \text{threadIdx.x}$$

- 内存线性化与行优先布局（Row-Major Layout）：虽然概念上数据是多维的，但在 C 和 CUDA C 中，动态分配的多维数组在物理内存中通常以一维数组形式进行**行优先（Row-Major）**存储（即将每一行依次首尾相连放置）。因此，2D 坐标映射到一维线性内存偏移（Offset）的计算公式为：

  - $$\text{Index} = \text{row} \times \text{Width} + \text{col}$$

- **边界条件检查：** 由于网格中线程的总数是线程块大小的整数倍，当实际数据大小（如图像宽和高）不能被线程块大小整除时，会产生多余的“非活跃”线程。因此，核函数中必须引入条件语句（如 `if (col < width && row < height)`）进行边界检查，以防止这些越界的非活跃线程发生非法内存读写。

- **应用案例（彩色图转灰度图）：** 核函数通过公式 \(L = 0.21 \times r + 0.72 \times g + 0.07 \times b\) 计算每个像素的亮度，展示了这种 2D 线程映射到行优先图像数据的基本应用。

### 3.3 图像模糊：一个更复杂的核函数 (Image Blur: A More Complex Kernel)

图像模糊（如邻域平均）是比向量加法和灰度图转换更复杂的案例，展示了线程开始需要获取邻域数据并进行复杂计算的场景。

- **计算逻辑：** 每一个线程计算一个输出像素，其值为输入像素周围 $(2 \times \text{BLURSIZE} + 1)^2$的方块区域（Patch）内所有有效像素的算术平均值。
- **边界处理：** 当目标像素位于图像边缘或角部时，其模糊窗口会延伸到图像范围之外（即出现 `curRow < 0` 或 `curRow >= height` 等情况）。核函数中加入了精细的条件判断，跳过这些不存在的像素（Ghost Cells 幽灵单元），并只对实际累加的有效像素数量（`pixels` 变量）进行除法，从而保证边缘区域平均值的准确计算。

### 3.4 矩阵乘法 (Matrix Multiplication)

矩阵乘法是线性代数（BLAS 库第 3 级标准）以及深度学习（如 CNN 卷积计算）中的核心运算，本章介绍了其最基础的单线程单元素核函数实现。

- **一对一线程映射：** 每个线程负责计算输出矩阵 $P$中的一个元素 $P_{row, col}$。
- 内积循环实现：计算 $P_{row, col}$ 的过程即为矩阵 $M $的第 row 行与矩阵 $N$ 的第 col 列做内积。其在 for 循环中的物理内存访问公式如下：
  - **访问 \(M\) 的元素：** `M[row * Width + k]`
  - **访问 \(N\) 的元素：** `N[k * Width + col]`
  - **输出写入：** 循环累加结束后，线程将结果写入一维线性空间中的对应位置 `P[row * Width + col]`。
- **规模限制：** 这种简单的一对一映射受限于 GPU 的最大块数及线程数等限制，当处理的矩阵规模超过此限制时，就需要通过主机端分块启动多个网格，或者修改核函数让一个线程计算多个输出元素。

### 本章总结

第三章深入揭示了 CUDA **多维线程映射机制** 以及 **物理内存线性化（行优先布局）** 的对应关系。这些针对多维网格线程坐标映射和边界判断的技巧，是掌握后续高性能并行模式（如 Stencil 模板计算、Shared Memory 共享内存分块优化、2D 卷积计算）的核心基石。
